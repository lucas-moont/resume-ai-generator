Vendored on 2026-08-21. Based on Wikipedia's "Signs of AI writing" (WikiProject AI Cleanup).

## Why this file is here

Reference material, not a live prompt. Nothing in `_vendor/` is composed into a system prompt
automatically — the leading `_` marks this tree as "keep out of composition".

The upstream skill is a **rewriter** (paste AI text → get a de-slopped rewrite) with its own
output modes. This product does not rewrite external text — it **generates** a resume JSON and
**advises** on LinkedIn copy. So the genuinely relevant part — the catalogue of AI-writing
tells and the non-negotiable "never invent a fact to sound human" rule — was **distilled** into
a generation-time style guard adapted to the product's contract:

| Distilled from (upstream) | Into (product prompt block) |
|---|---|
| `humanizer/SKILL.md` (35 patterns + truthfulness + false-positive guards) | `../humanizer.md` |

`../humanizer.md` is composed onto the generation, refine, and LinkedIn-analysis system prompts
(see `app/prompt_loader.py`).

## Do not

- Do not wire `_vendor/**` into a prompt verbatim: it is 450+ lines and carries output-mode
  instructions ("return the draft + a list + the final rewrite") that would break this app's
  JSON-only / advice-only contracts.
- Do not import the upstream's blanket em-dash ban: `system/generate.md` deliberately uses an
  em dash in the headline format. The distilled block scopes prose tells only, never formatting.
- Do not edit this file to change agent behavior — edit `../humanizer.md`.
